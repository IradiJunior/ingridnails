# Ingrid Freitas | Método DNA

Catálogo de materiais com 42 produtos, busca e filtros por categoria.

## Abrir

Baixe `index.html` e abra no navegador ou publique o arquivo na raiz de uma hospedagem estática. Estilos, scripts, catálogo e imagens estão incorporados no HTML. As fontes externas e os links de compra precisam de internet.

## Atualizações

Esta é uma cópia estática do catálogo. Alterações futuras no painel do site original não atualizam automaticamente este repositório; é necessária uma nova exportação do HTML.
